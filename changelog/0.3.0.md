# S++ 0.3.0

## Async and await

- `await` is a new keyword, written as a postfix operator: `fut.await`. Only a `Fut` can be awaited, and anything else
  is the new "Await Target Not Future" error.
- `async f(a, b)` lowers to `Fut[T]::spawn` over a closure that makes the call, rather than passing the target and its
  arguments to `sppc::async`.

## Default values

- A default parameter or attribute value is copied into every call or object initialiser that leaves it out, so it is
  now limited to an expression that creates no scope.
- A `cmp` generic parameter's default is folded where it is declared, so a default that is not a constant is reported
  even when nothing uses it.
- A `cmp` value that depends on a `cmp` generic is folded again before it is lowered, so the emitted constant is the
  resolved value.

## `Self`

- Lots of fixes regarding how `Self` is used and translated, the stages this happens at, and unresolvable sites. Unit
  tests have increased coverage for them.

## Closures and memory analysis

- Fix linear memory analysis for closures, requiring some of the STD types to be made copyable as they should have
  already been.

## Diagnostics and tooling

- Several null pointer crashes fixed, in type comparison, type identifiers, and the AST utilities.

## CI

- A new STL conformance step starts from an empty directory and runs `spp init`, `spp build` and
  `spp test --all-libs`. It runs on one shard of each release variant and on the release build.
- Dependabot should no longer trigger massive pipeline runs like it has been on PR and merge.
- The generator for `ast_kind.ixx` and `ast_kind_range.ixx` has a `--check` mode for catching a stale generated file in
  the pre-commit hook.

## Documentation

- The compile-time safety guarantees page marks `cmp` data in `.rodata`, immutable globals and full RELRO linking as
  done, and explains how `async` and `await` relate to the concurrency guarantees.
